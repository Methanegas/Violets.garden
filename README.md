# About This Project
I'm Violet, an engineering student interested in embedded systems, software development, music, and nature!

I wanted to create a portfolio that felt less like a traditional website and more like using an actual desktop computer because I thought it would be fun and more interactive. Violets.garden recreates the look of an old GNOME desktop environment, with interactive applications inspired by their real-world counterparts, with similar functionality. 

# Features
- **Interactive Desktop** - Explore a desktop environment inspired by classic Unix systems with "retro" icons, and window styling.
- **Window Management**- Open, move, and interact with application windows.
- **Terminal** - Explore the portfolio through a command-line interface and mess around with stupid commands.
- **Projects** - Gateway to learn about my engineering and software projects.
- **Music Player** - Listen to my music through an integrated music player based on [foobar2000](https://www.foobar2000.org/).
- **Image Gallery** - View my photography through an photography workflow app, [darktable](https://www.darktable.org/).
- And more to come!
